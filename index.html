Downloads that finish.

Master Download Manager takes a file apart across many connections, keeps it resumable across crashes and restarts, and puts video, image galleries and torrents in the same list as everything else.

Windows 10 and 11 · macOS · Linux · Portable build available

Every feature

Downloads

Segmented downloads

One file, many connections. The engine splits large files, reopens what drops and rejoins the segments as they finish. HTTP, HTTPS and FTP.

Crash-safe resume

A part file beside the destination carries its own state, so a restart or a lost connection continues where it stopped.

Queues and batches

A main queue, a later queue and a batch queue, with a maximum number of connections per server and per file.

Scheduler

Start and stop queues at a time and on the days you pick, with retries for what fails.

Speed limits

Per-download and global limits, in either direction, so a large download does not take the whole line.

Categories and folders

Categories by file type, each with its own folder — or one folder for everything.

Checksums

Verify a finished file against MD5, SHA-1 or SHA-256 without leaving the app.

Archive extraction

Extract .zip, .tar and .xz after the download; RAR and 7z through a 7-Zip you already have.

Duplicate handling

Recognises a link you have already added and asks what to do instead of downloading it twice.

Sources and media

Browser capture

A native messaging host hands downloads from Chrome, Chromium, Edge, Brave, Opera, Vivaldi and Firefox to the app, with the page, the referrer and its cookies.

Video and audio

Page downloads through yt-dlp, with lux, Streamlink and Ember as fallbacks for pages yt-dlp cannot read; live streams through Streamlink; quality and format choices.

Image galleries

Whole galleries through gallery-dl, with folders named after the site and the set.

BitTorrent

Magnets and .torrent files in the same list, with seeding limits, blocklists, port forwarding and proxy support.

Link grabber

Reads a page and lists every link on it, with filters by type, so a batch of files is one click.

RSS feeds

Watches a feed and adds what it matches.

Debrid accounts

Real-Debrid, AllDebrid and Premiumize can fetch a link for you; the tokens stay in the system keychain.

Site logins

Credentials per site, kept in the system keychain, for the servers that ask.

Network

Proxy support

HTTP, HTTPS and SOCKS proxies, from the settings, the system, the browser or a PAC script.

DNS options

System DNS, or DNS over HTTPS with a provider you choose, per network.

Network adapter

Bind downloads to one interface when a machine has several.

Remote control

Off by default. When you turn it on, paired phones and computers on your own network add downloads over HTTPS.

The application

Command line

The classic /d /p /f /a /n /s switches, a terminal downloader with JSON output, and a local API for other programs.

MCP server

An assistant that speaks the Model Context Protocol can add and watch downloads.

Themes

Built-in looks for Windows, macOS and Linux, light and dark, with the interface size and font weight you choose.

85 languages

The interface, dates, numbers, sizes and speeds follow the language you choose.

Tray and portable mode

Keeps running in the notification area, or keeps its settings beside the program in a portable folder.

Accessibility

Keyboard navigation throughout, the system's accessibility tree, and Windows' high contrast.

Crash reports

A crash is written to a file in the app's data folder — nothing is uploaded.

Private by construction

No telemetry, no analytics, no account, no advertising. The local API listens on 127.0.0.1 behind a token.
